# CONVIVE · Iteration 1 code

Team 102_A (Convive Lab) · Mobile Data Challenge 2026, Challenge #2 "Visitors and residents in the same space".

This folder is the **Iteration 1 product increment** committed in the Project Work Plan (SC-04): the notebook structure, the base neighbourhood map, and the data review and cleaning plan. It also contains a full analytical toolkit, built and validated before the data arrive.

> ⚠️ The Telefónica Tech data are not available yet. The notebook runs on **synthetic data** with exactly the same columns as the official description ("Smart Steps - Challenge 2026"). **All numbers and patterns are made up.** Because the synthetic model is known, each method is also validated: we check that it recovers what was planted.

## What the notebook contains

| § | Content | Methods |
|---|---|---|
| 1 | Data catalogue and interpretation rules | 12 files, rules from the data description |
| 2 | **Data review and cleaning** | Schema and content checks, coverage calendar, cross-file consistency (unique visitors are not additive), logged cleaning actions, detection of planted problems |
| 3 | **Base neighbourhood map** | 73 neighbourhoods linked to Smart Steps codes, areas, centroids, k-nearest-neighbour spatial weights |
| 4 | When | Robust harmonic regression (trend + yearly Fourier cycle + weekday effect), event detection on 76 series (100% of the 17 planted events found), same-weekday year-on-year change |
| 5 | Where | Density per km², location quotients, Gini and Lorenz curves, Moran's I and LISA hot spots, mean centre and standard distance, growth on equivalent periods |
| 6 | Neighbourhood typologies | k-means on 7 indicators, silhouette selection, PCA |
| 7 | Visitors vs residents | Gravity model with fixed effects **corrected for the privacy threshold** (censored Poisson MLE), PageRank, visitor share of arrivals |
| 8 | Coexistence Pressure Index | Composite index with a weight-sensitivity analysis (500 random weightings) |
| 9 | Who | Country seasonality and growth, length of stay |
| 10 | Traceability | Coverage of the PWP requirements RQ-01 to RQ-18, limitations, next steps |

## How to run

```bash
pip install -r requirements.txt
jupyter notebook CONVIVE_Iteration1.ipynb     # then "Run All" (about 1 minute)
```

The notebook is saved already executed, so it can also be read directly on GitHub. On the first run it generates the synthetic files in `data/sample/`.

## Using the real data

1. Copy the Telefónica files into `data/raw/` with their official names (e.g. `visitantes_unicos_barrio_yearmon.csv`). CSV (`,` or `;`) and Parquet are supported.
2. Run the notebook again. With `DATA_MODE = "auto"` it uses the real files when they exist and the synthetic ones otherwise (the source of each file is printed in §1.2).
3. **Never commit the real data.** `data/raw/` is in `.gitignore` because of the confidentiality agreement.

The mobility file names (M1 to M3) are not given in the data description. They are placeholders in `convive.py` (`SCHEMAS`), to be updated when the data arrive.
