## Likely questions

- *Why 15% of 73 for concentration?* A cut-off we set before computing; the dashboard shows the number, so another threshold changes only the verdict.
- *Can you add visitors across neighbourhoods?* No. Unique visitors are not additive; the sums are presences and are labelled so.
- *Why not M3?* 43.7% of its rows repeat a key with different values (I7); we use it only after the explanation.
- *Is the -7.6% at weekends significant?* The 95% bootstrap interval is -9.0% to -6.3%.
