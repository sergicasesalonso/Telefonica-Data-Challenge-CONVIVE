# 4.1.1 Dashboard layout and navigation

CONVIVE · Team 102_A · Iteration 2 · Owner: Martí Casas Niubó

One scrolling page with a fixed sidebar, so the filters stay visible and the demo needs no navigation between tabs. Every block has a title naming its question and a one-line limitation below it. The sketch is in `4.1.1_dashboard_layout.png`, generated by `app/make_layout_sketch.py`.

## Design rules

- **Same colour per origin everywhere** (Okabe-Ito, colour-blind safe): Internacional blue, Nacional orange, Regional green, Residente pink. Palette checked with a CVD validator.
- **Never colour alone:** legends, line markers, direct line labels, a texture for excursionists and a table under the charts.
- **The two measures are kept apart:** the trips view comes last, and its title says "Trips, not people".
- **Maps use one-hue scales**, except the change map, which uses a diverging scale centred on 0.
