# 4.1.3 Visualisation environment selection

CONVIVE · Team 102_A · Iteration 2 · Owner: Martí Casas Niubó

**Decision: Streamlit, run locally.** The professor asked us to "keep it simple", and Streamlit gives a filterable dashboard using the Python code we already have. Nothing is uploaded, because the app reads local aggregated tables and runs on `localhost`.

| PWP criterion | Streamlit (local) | Jupyter + Plotly + ipywidgets | Power BI Desktop |
|---|---|---|---|
| NDA-safe (runs locally, no cloud upload) | **Yes**, if run on `localhost` and not on Streamlit Cloud | **Yes**, local kernel | **Yes** on Desktop; the Publish button would upload, so it needs discipline |
| Learning effort for the team | **Low:** plain Python, few commands | Medium: widget callbacks and layout take effort | Medium: new tool and DAX; no Python skills reused |
| Reuse of our Python code | **High:** imports `convive.py` directly | **High** | Low: logic rebuilt in Power Query or DAX |
| Filters | **Good:** sidebar widgets, every view recalculates | Possible, but wired by hand | **Good:** native slicers, but rules such as "monthly mean, never sum" must be rewritten as measures |
| Demo quality | **Good:** clean web page; code stays hidden | Medium: code and notebook layout are visible unless Voilà is added | **Good:** polished, though choropleths on custom neighbourhood shapes take extra setup |
| Cost | **0 EUR** | **0 EUR** | 0 EUR for Desktop; sharing needs a paid licence |

## Why Streamlit

- It is the only option that scores well on all six criteria without extra tools.
- The non-additive rule for unique visitors lives in one tested Python module (`app/dashboard_data.py`), rather than being rebuilt in another tool.
- Plotly draws the maps from our GeoJSON with no map tiles or basemap file, so the page makes no external requests and works without internet (tested with the network blocked).

## Conditions of use

- Run only with `streamlit run` on the local computer. Do not deploy to Streamlit Community Cloud or any other host.
- The app reads only `deliverables/iteration2/3.1.6_stats/*.csv` and the neighbourhood GeoJSON.

## Test page

`app/hello_streamlit.py` is a minimal page with no project data: `streamlit run app/hello_streamlit.py`.
